# Three interview demonstration options

Use one option for a ten-minute conversation. Let the reviewer edit a fixture and predict the outcome before running it. Explain the customer problem first, the algorithm second, and the unresolved production boundary third.

## Option 1 — Enterprise AI delivery

**0:00–1:00:** A support team needs current policy evidence without crossing a tenant boundary.

**1:00–4:00:** Run ProofDesk. Show the current cited policy. Change roles to an unauthorized role; show abstention. Explain why resolving versions before ACL filtering prevents access to a superseded version after revocation.

**4:00–7:00:** Run EvalForge. Explain case alignment, critical failures and quality/cost/latency tradeoffs. Introduce a critical regression; show the release hold.

**7:00–9:00:** Explain MCP: the agent can request a calculation, but the allowlisted tool does not deploy, pay, execute commands or trust document instructions.

**9:00–10:00:** Discuss trusted identity, real model outputs, held-out evaluations and a pilot acceptance gate as next steps.

## Option 2 — Customer integration and data delivery

**0:00–1:00:** A CRM migration has duplicates and conflicting identities; a quiet wrong merge is worse than visible quarantine.

**1:00–4:00:** Run Dockyard. Trace an accepted field back to its source cell. Inject a conflicting account/email pair. Show quarantine and row-count conservation.

**4:00–7:00:** Run Relay. Show a duplicate, a transient failure and out-of-order versions. Open the restart and transaction-rollback tests; distinguish SQLite transaction guarantees from external delivery.

**7:00–9:00:** Run LedgerGuard. Increase invoice quantity or change currency. Explain holds and the all-or-nothing reservation of invoice lines.

**9:00–10:00:** Propose a migration dry-run and shadow webhook sink with a customer-owned reconciliation report.

## Option 3 — Operational decision engineering

**0:00–1:00:** A dispatcher must promise only what capacity and time windows allow.

**1:00–4:00:** Run RouteCraft. Reduce vehicle capacity. Explain unassigned jobs and why distance comparisons require the same served jobs.

**4:00–7:00:** Run ShiftForge. Add maintenance or a missing skill. Show dependency blocking and nonoverlapping machine schedules. Relate it to manufacturing or a media/render queue.

**7:00–9:00:** Run Switchboard or LaunchGate. Explain heuristic evidence versus a proven root cause, or measured telemetry versus an automatic production action.

**9:00–10:00:** Discuss collecting actual durations, road times or incident history before measuring business impact.

## Evidence to show

Use `evidence/verification.json`, a relevant failure test and the project case study. Do not say a synthetic metric is customer savings. Do not describe the interface as deployed AI or a static replay as a new execution. Be prepared to explain every validation and tradeoff rather than relying on the project names.
